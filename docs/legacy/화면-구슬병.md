# 퇴사각 펫 — 캘린더 · 대시보드 화면: 구슬병

> 기획 요구사항: 답변한 날만 표시, 클릭하면 그날 답변 표시, 직장인 유형과 항목별 점수 제공, 답변 전 최소~최대값 가이드
> 데이터 구조는 [ERD.md](ERD.md) 그대로 사용. 이 문서는 **보여주는 방식**만 다룸

## 1. 컨셉

> **하루 = 구슬 하나. 답을 하면 펫이 구슬을 물고 와서 바탕화면의 유리병에 넣는다.**

```
        ╭───╮
      ╭─╯   ╰─╮
      │ ●  ◉  │      구슬 색 = 그날 퇴사각
      │◉ ● ● ◉│      병을 누르면 → 구슬이 쏟아져 달력으로 정렬
      │● ◉ ●● │      구슬을 누르면 → 그날 답변
      ╰───────╯
         🐾
```

### 왜 구슬병인가
- **바탕화면에 늘 떠 있다**: 일반 앱은 화면을 열어야 데이터가 보이지만, 데스크톱 펫은 늘 화면에 있음. 이번 달 병이 차오르는 걸 일하면서 곁눈으로 봄
- **기록하는 순간이 보상**: 답변 → 펫이 구슬을 넣음 → 병이 차오름이 하나의 연출로 이어짐
- **만지고 싶은 데이터**: 병을 흔들면 구슬이 출렁임 (물리 효과)
- **탓하지 않음**: 답하지 않은 날은 구슬이 없을 뿐, 빈칸 · 결근 표시 같은 부정적 표현 없음

## 2. 구슬 한 개가 담는 정보

| 시각 요소 | 의미 | 데이터 |
| --- | --- | --- |
| **색** | 그날 퇴사각 | `score_snapshots` (DAY, 전체) — 0 맑은 파랑 → 50 보라 → 100 빨강 (연속 그라데이션) |
| 빛남 | 가장 최근 구슬 | 오늘 넣은 구슬이 맨 위에서 은은하게 빛남 |
| 크기 | (결정 필요) | 안 1: 모두 같은 크기 / 안 2: 그날 기록량 (질문 + 하루 기록 + 메모) |

- **색만으로 구분하지 않음**: 마우스를 올리면 날짜와 점수 숫자를 항상 함께 표시 (색약 사용자 고려)
- 하루에 구슬은 **하나**. 질문 2개 중 1개만 답해도 구슬이 생기고, 나머지를 답하면 색이 바뀜

## 3. 화면 상태와 전환

```
 ① 병 (평소)            ② 쏟기                 ③ 펼친 달력              ④ 상세
    ╭───╮                 ╭───╮             11월                   ┌─ 11월 14일 ─┐
  ╭─╯   ╰─╮             ╭─╯   ╰─╮          월 화 수 목 금            │ 퇴사각 76    │
  │ ●  ◉  │   클릭 →     │  ↘ ↘  │   →      ●  ◉     ◉  ●    클릭 →   │ 도장 8번  80 │
  │◉ ● ● ◉│             ╰──●◉●──╯          ◉  ●  ●     ◉           │ 풍선 7/10 72 │
  ╰───────╯              ●  ◉ ● ◉          ●  ●  ◉  ◉              │ 기분·메모    │
                                                                 └────────────┘
```

| 상태 | 무엇을 보나 | 들어가는 방법 | 나가는 방법 |
| --- | --- | --- | --- |
| ① 병 | 이번 달 요약, 만지는 재미 | 기본 상태 | — |
| ② 쏟기 | 전환 애니메이션 (약 1초) | 병 클릭 | 자동으로 ③ |
| ③ 펼친 달력 | 정확한 날짜별 확인 | ② 이후 | 닫기 → 구슬이 다시 병으로 빨려 들어감 |
| ④ 상세 | 그날 답변 · 기분 · 메모 | 구슬 클릭 (①, ③ 어디서든) | 닫기 |

### 핵심 원칙: 같은 구슬이 이동한다
- 달력이 새로 나타나는 게 아니라, **병 속 구슬이 각자 자기 날짜 칸으로 굴러가서** 달력이 됨
- 그래서 "병 속 저 빨간 구슬이 11월 14일이었구나" 가 자연스럽게 연결됨
- 답하지 않은 날은 구슬이 없어서 빈칸 → 기획의 "답한 날만 표시" 와 그대로 맞음

### 병 상태에서 바로 보기
| 동작 | 결과 |
| --- | --- |
| 구슬에 마우스 올리기 | 작은 말풍선: "11/14 (금) · 76" |
| 구슬 클릭 | ④ 상세 패널 바로 열기 |
| 병 드래그 | 병 위치 이동 (펫처럼 바탕화면 아무 곳에) |
| 병 흔들기 (빠르게 드래그) | 구슬이 출렁임 |

### ④ 상세 패널
- 답변은 숫자만이 아니라 **답할 때의 연출로 다시 보여줌**: "사직서 도장 8번", "🎁 귀중품" (`questions.interaction_key`, `question_options.asset_key`)
- 하루 기록: 오전 · 오후 · 퇴근 기분, 야근, 메모 3종 (`get_daily_records()` 로 복호화)

## 4. 다른 달 보기 — 선반

```
  선반  ┌───┐ ┌───┐ ┌───┐
       │9월│ │10월│ │11월│      ← 이번 달 병은 바탕화면에
       └───┘ └───┘ └───┘
```

- 월말이 되면 병뚜껑이 닫히고 **선반으로 올라감** (펫이 옮기는 연출)
- 선반은 대시보드 창 안에 있음. 선반의 병을 누르면 똑같이 쏟아져서 그 달 달력이 됨
- 펼친 달력에서 ◀ ▶ 로 옆 달 병으로 이동
- 1년이 지나면 선반에 병 12개 → 연간 요약

## 5. 대시보드 — 직장인 유형과 항목별 점수

| 요소 | 보여주는 방식 | 데이터 |
| --- | --- | --- |
| **직장인 유형** | **병에 붙은 라벨**. 라벨을 누르면 유형 이름 · 설명 카드 | `worker_types` |
| **항목별 점수** | 퇴사 충동 n점, 업무 스트레스 n점 … 점수 높은 순 목록 | `score_snapshots` (지표별) |
| **조건으로 찾기** | 항목을 누르면 **그 항목 점수가 높았던 날의 구슬만 빛나고** 나머지는 흐려짐 (병 · 달력 모두) | `score_snapshots` (DAY, 지표별) |
| **데이터 부족** | 라벨 자리에 "2일만 더 답하면 유형이 나와요" | `answer_count` |

```
      ╭───╮
    ╭─╯   ╰─╮
    │ ●  ◉  │
    │┌─────┐│  ← 라벨: "🔥 번아웃 직전형"
    │└─────┘│
    ╰───────╯

    퇴사 충동     80  ▸   ← 누르면 해당 구슬만 빛남
    업무 스트레스  72  ▸
    성취감       30  ▸
```

## 6. 튜토리얼 — 답하기 전 최소~최대값 가이드
- 처음 실행 때 한꺼번에 설명하지 않고, **각 설문 연출이 처음 나올 때만** 기준을 보여줌 (풍선 질문이 처음 나오면 풍선 가이드)
- 질문 화면에는 양 끝 설명(`min_label` / `max_label`)을 항상 작게 표시
- 언제든 다시 볼 수 있는 "?" 버튼
- 구슬병 자체의 사용법(쏟기, 흔들기)은 첫 구슬이 들어갈 때 펫이 말풍선으로 한 번 알려줌

## 7. 구현 메모
- **물리 효과**: `matter.js` (2D 물리 엔진)로 Electron 렌더러에서 구현. 구슬 31개 이하라 성능 부담 없음
- **병 창**: 펫과 같은 투명 · 항상 위 창. 병 영역만 클릭을 받고 나머지는 클릭 통과
- **쏟기 전환**: 물리를 끄고 각 구슬을 목표 날짜 칸 좌표로 애니메이션 이동 → 돌아갈 때는 병 위에서 다시 물리를 켜고 떨어뜨림
- **병 숨기기**: 트레이 메뉴에서 펫과 별도로 켜고 끔
- 데이터 구조 변경 없음. 모두 기존 테이블을 그리는 방식만 다름

## 8. MVP 범위

| 우선순위 | 기능 |
| --- | --- |
| **MVP** | 병 + 구슬 쌓기 (물리), 마우스 올리기 툴팁, 구슬 클릭 → 상세, 병 클릭 → 쏟기 → 펼친 달력 |
| **MVP** | 병 라벨(유형) + 항목별 점수 목록 |
| 다음 | 펫이 구슬을 물고 와서 넣는 연출, 병 흔들기 |
| 다음 | 항목 클릭 → 해당 구슬만 빛나기 |
| 나중 | 선반 (지난달 병들), 월말 병뚜껑 닫기 연출 |
| 나중 | 주간 생성 아트 (그 주 점수로 펫이 그린 추상화) — 공유용 보상 |

## 9. 정해야 할 것
1. **구슬 크기**의 의미: 모두 같게 vs 기록량에 비례
2. **색 단계**: 연속 그라데이션 vs 3단계(괜찮음 / 지침 / 퇴사각)
3. **날짜끼리 비교 가능하게 할지**: 하루 질문 2개가 랜덤이면 날마다 점수 기준이 달라짐 → "매일 고정 질문 1개 + 랜덤 1개" 로 하고 구슬 색은 고정 질문 기준으로 할지
4. 병 기본 위치 (펫 옆 / 화면 오른쪽 아래 고정 / 사용자가 배치)
