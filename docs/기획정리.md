## 1. 유령 캐릭터

| 항목 | 내용 |
| --- | --- |
| 화면에 떠 있는 방식 | 배경 없이 유령만 보임. 다른 창보다 **항상 위**, **작업표시줄 바로 위**에 있음 |
| 유령의 행동 | 가만히 있기, 걸어다니기, 음악 듣기, 졸기, 파일 먹기, 구슬 들고 가기 |
| 졸기 | 사용자가 일정 시간 컴퓨터를 안 만지면 꾸벅꾸벅 졸기 시작. 다시 움직이면 깨어나서 한마디 |

## 2. 유령이 하는 말

| 항목 | 내용 |
| --- | --- |
| 말을 거는 순간 | 처음 실행, 출근, 점심 전, 오후, 퇴근 전, 늦은 밤, 클릭했을 때, 졸다 깼을 때, 질문이 도착했을 때, 공휴일 |
| 말풍선 | 같은 말이 너무 자주 반복되지 않게 간격을 둠. **친해질수록 말투가 바뀜** ([8. 친밀도](#8-친밀도)) |

## 3. 오늘의 질문 (단기)

### 흐름

```
질문 도착 ──→ 질문에 답하기 ──→ 몇 개 답했나요?
                                  │
                                  ├─ 첫 번째 답 ──→ 오늘의 구슬 만들기 (자동) ──→ 5. 구슬 넣기 연출
                                  │
                                  ├─ 두 번째 · 세 번째 답 ──→ 오늘 구슬에 답변만 추가 (새 구슬 없음)
                                  │
                                  └─ 0개 ────→ 그날은 구슬 없음
```

> **사용자가 따로 할 일은 없음.** 답하기만 하면 구슬이 생기고, 더 답한 내용은 같은 구슬에 담김. 하루 구슬은 **1개**

### 단계별 내용

| 단계 | 내용 |
| --- | --- |
| 질문 도착 | **오후 4시쯤** 유령 머리 위에 질문 아이콘이 뜸. **눌러야** 질문이 시작돼서 일을 방해하지 않음 |
| 질문에 답하기 | 질문 **5개 중 매일 3개가 랜덤**으로 나옴. 하루 **최대 3개**까지 답할 수 있음 |
| 첫 번째 답 | 버튼 없이 **바로 오늘의 구슬이 만들어지고** 구슬 넣기 연출이 시작됨 |
| 두 번째 · 세 번째 답 | 새 구슬은 생기지 않고, 답변이 **오늘 구슬에 추가**됨 (구슬 눌러보기에서 확인) |
| 남은 질문 | 1~2개만 답하고 끝내도 됨. 남은 질문은 **자정 전까지 언제든** 이어서 답할 수 있음 |
| 0개 답함 | 답하지 않아도 불이익 없음. 질문 아이콘은 **그날 밤 자정에 사라짐** |

### 질문 목록 (단기 지표 5개) — 확정

| 평가 항목 | 질문 | 주기 | 설문 방식 (답변 연출) |
| --- | --- | --- | --- |
| 퇴사 충동 | 오늘 회사를 그만두고 싶다는 생각이 얼마나 들었나요? | 매일 | 충동만큼 **사직서에 도장 찍기** |
| 업무 스트레스 | 오늘 업무로 인해 얼마나 스트레스를 받았나요? | 매일 | 받은 스트레스만큼 **풍선 크게 불기** → 다 불고 나면 터뜨려서 날려버리기 |
| 업무량 | 오늘 업무량은 감당할 수 있는 수준이었나요? | 매일 | 느낀 업무량만큼 **서류 쌓기**. 쌓인 높이를 m로 표현해서 랜드마크와 비교 |
| 감정 소모 | 오늘 직장에서 감정적으로 얼마나 지쳤나요? | 매일 | **HP바 슬라이더** (최대값 100) |
| 성취감 | 오늘 업무를 마치고 얼마나 뿌듯함을 느꼈나요? | 매일 | **도장 3개 중 1개** 선택: 때려치워 / 이걸해냄 / 내가짱이야 |

- 매일 이 5개 중 **3개가 랜덤**으로 나옴

### 구슬 색 — 우선 단색

- 오늘의 구슬은 **모두 같은 색(단색)**. 점수에 따라 색을 나누지 않음
- 특별한 구슬만 반짝이는 등 **모양으로 구분** ([4. 이달의 질문](#4-이달의-질문-장기))
- 답변 점수는 저장해 두므로, 나중에 점수별 색을 넣을 수 있음

## 4. 이달의 질문 (장기)

```
이벤트 도착 ──→ 질문 고르고 답하기 ──→ 특별한 구슬 만들기 ──→ 5. 구슬 넣기 연출
```

| 단계 | 내용 |
| --- | --- |
| 이벤트 도착 | **한 달에 한 번 정해진 날** 유령이 특별한 질문을 들고 옴 |
| 질문 고르고 답하기 | 질문 **3개 중 마음에 드는 1개**를 골라 답함 |
| 특별한 구슬 만들기 | 오늘의 구슬과 **따로 1개가 더** 생김. 반짝이는 등 **모양을 다르게** 해서 구분 |

### 질문 목록 (장기 지표 3개) — 확정

| 평가 항목 | 질문 | 주기 | 설문 방식 (답변 연출) |
| --- | --- | --- | --- |
| 복지 | 현재 회사의 복지 제도가 내 생활에 실질적으로 도움이 되나요? | 분기별 | **선물 상자 열기** → 나온 선물: 쓸모 있음 / 그럭저럭 / 귀중품 |
| 조직문화 | 회사의 업무 방식과 의사결정 과정에 만족하나요? | 분기별 | **회의할 때 내 모습** 고르기: 편한 자세 / 그냥 앉아 있는 자세 / 군기 들어있는 자세 |
| 고용 · 사업 안정성 | 회사의 미래와 나의 고용 안정성에 대해 얼마나 긍정적으로 생각하나요? | 분기별 | **우리 회사의 날씨** 고르기: 맑음 / 구름 / 폭풍 |

- 이달의 질문 이벤트에서 이 3개가 나오고, 마음에 드는 1개를 골라 답함

## 5. 구슬 넣기 연출

오늘의 구슬, 특별한 구슬 모두 같은 연출을 씀.

| 항목 | 내용 |
| --- | --- |
| 구슬 넣기 순서 | ① 구슬 등장 → ② 유령 옆에 이번 달 유리병 등장 → ③ 유령이 구슬을 들고 병까지 감 → ④ 병에 쏙 넣기 → ⑤ 병이 사라짐 |
| 별도 창 없음 | 모든 연출이 **유령 주변에서만** 일어나고 따로 창이 뜨지 않음 |

## 6. 유리병 선반 (기록 보기)

> **유령을 우클릭했을 때만** 유령 옆에 선반이 나타남. 평소에는 보이지 않음

| 항목 | 내용 |
| --- | --- |
| 보이는 때 | 유령 **우클릭** → [우클릭 메뉴](#9-우클릭-메뉴)와 함께 유령 옆쪽에 선반이 나타남 |
| 사라지는 때 | 우클릭 메뉴를 닫으면 선반도 함께 사라짐. 바탕화면에 따로 떠 있지 않음 |
| 선반 | **유리병 1개 = 한 달**. 지난 달 병들이 선반에 순서대로 진열됨. 이번 달 병은 아직 채우는 중으로 보임 |
| 유리병 눌러보기 | 그 달의 구슬이 **날짜별로 펼쳐짐**. 답한 날을 한눈에 볼 수 있음 |
| 구슬 눌러보기 | 그날의 **퇴사각 지수(숫자)** 와 **하루 기록(그날 질문에 대한 답변)** 을 보여줌. **특별한 구슬은 이달의 질문 답변**을 보여줌 |

### 구슬을 눌렀을 때 보이는 정보

| 정보 | 내용 |
| --- | --- |
| 퇴사각 지수 | 그날의 점수 (0~100, 높을수록 퇴사각↑). **숫자로만** 보여줌. 구슬 색에는 반영하지 않음 (구슬은 단색) |
| 하루 기록 | 그날 답한 질문과 고른 답 (답변 연출 결과 포함, 예: "사직서 도장 8번") |

## 7. 파일 먹기

| 항목 | 내용 |
| --- | --- |
| 파일 주기 | 지우고 싶은 파일을 유령에게 **끌어다 놓으면** 콰작콰작 먹음 |
| 실제 처리 | 파일은 완전히 지워지지 않고 **휴지통으로** 감. 실수해도 되살릴 수 있음. **폴더나 중요한 시스템 파일은 먹지 않음** |

## 8. 친밀도

### 친밀도가 오르는 요인 (3가지) — 확정

| # | 요인 | 기준 |
| --- | --- | --- |
| 1 | 유령 쓰다듬기 | 유령을 쓰다듬으면 오름 |
| 2 | 질문 답변 여부 | **하루 단위**로 그날 질문(단기 · 장기)에 답했는지. 답변 **개수는 보지 않음** |
| 3 | 유령이 나타나 있던 시간 | 데스크톱에 유령이 나타나 있던 시간만큼 오름 |

- 파일 먹이기는 친밀도에 반영하지 않음
- **하루에 쌓을 수 있는 양은 정해져 있고**, **줄어들지 않음**

### 친해지면

| 항목 | 내용 |
| --- | --- |
| 단계 | **5단계** |
| 변화 | 단계가 오를수록 말투가 편해지고 새로운 대사와 행동이 열림 |

## 9. 우클릭 메뉴

> 우클릭하면 메뉴와 함께 [유리병 선반](#6-유리병-선반-기록-보기)이 유령 옆에 나타남. 그래서 메뉴에 "기록 보기"는 따로 두지 않음

| 메뉴 | 내용 |
| --- | --- |
| 이름 짓기 / 바꾸기 | 유령 이름 설정 |
| 숨기기 | **30분, 1시간, 3시간** 동안 숨기기. 다시 나타나기. **단축키**로 바로 숨기기 |
| 행동 및 크기 | 걸어다니기 또는 가만히 있기, 중력, 크기(작게 / 기본 / 크게), 투명도 |
| 말하기 | 말하기 켜기 / 끄기, 말 거는 빈도 **5단계**, 말풍선이 떠 있는 시간 |
| 설정 | 질문 받을 시간, 언어, 컴퓨터 켜면 자동 실행, 계정 연결, 업데이트 확인 |
| 종료 | 앱 종료 |

## 10. 트레이 아이콘

| 항목 | 내용 |
| --- | --- |
| 메뉴 | 유령 다시 부르기, 기록 보기, 설정, 종료 |
| 역할 | 유령을 숨겨둔 상태에서도 **화면 오른쪽 아래 아이콘**으로 모든 메뉴를 쓸 수 있음 |

## 11. 저장되는 정보

| 구분 | 내용 |
| --- | --- |
| 답변 기록 | 날짜, 질문 종류(오늘의 질문 / 이달의 질문), 질문, 고른 답, 점수(0~100) |
| 메뉴 설정값 | 질문 받을 시간, 크기, 투명도, 말 거는 빈도, 숨김 여부, 언어 |
| 유령 정보 | 유령 이름, 친밀도 점수와 단계 |

## 12. 이번 기획에 없는 기능

기존 문서([ERD.md](legacy/ERD.md), [화면-구슬병.md](legacy/화면-구슬병.md))에 있었지만 **이번 기획에서는 만들지 않음**

| 기능 | 비고 |
| --- | --- |
| 직장인 유형 · 항목별 점수 (병 라벨, 대시보드) | 없음 |
| 하루 기록 직접 입력 (오전 · 오후 · 퇴근 기분, 야근, 메모 3종) | 없음. "하루 기록" = 그날 질문에 대한 답변 |
| 업무 기록 | 없음 |
| 관리자 웹 | 이번 범위에서 제외. **나중에 만들 예정** → DB 는 나중에 붙일 수 있게 설계 |
| 펫 종류 뽑기 | 없음. 유령 하나로 고정 |
