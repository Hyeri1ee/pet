## A. 기존 문서와 다른 부분

### A-1. ✅ 하루 질문 개수 · 단기 지표 — 결정 (2026-11-18)
**결정: 단기 지표 5개, 매일 3개 랜덤**

| 평가 항목 | 설문 방식 |
| --- | --- |
| 퇴사 충동 | 사직서에 도장 찍기 |
| 업무 스트레스 | 풍선 불기 → 터뜨리기 |
| 업무량 | 서류 쌓기 (높이 m, 랜드마크 비교) |
| 감정 소모 | HP바 슬라이더 (최대 100) |
| 성취감 | 도장 3개 중 1개 (때려치워 / 이걸해냄 / 내가짱이야) |

- 질문 · 설문 방식 상세는 [기획정리.md](기획정리.md) 3. 오늘의 질문
- 남은 작업: [ERD.md](legacy/ERD.md) 의 "단기 지표 7개 · 하루 2개" → **5개 · 하루 3개**로 수정, `draw_daily_questions()` 규칙 수정
- 참고: 풀이 5개라 같은 질문이 자주 반복됨 → "최근 3일 가중치 낮춤" 규칙을 유지할지는 개발 때 확인

### A-2. ✅ 1~2개만 답했을 때 구슬 처리 — 결정 (2026-11-18)
**결정: 첫 답에 자동 생성** (구슬 색은 단색으로 정해져서 색 갱신은 없음, A-3)

- 첫 번째 답을 하면 오늘의 구슬이 바로 생기고 구슬 넣기 연출 시작
- 두 번째 · 세 번째 답은 **같은 구슬에 답변만 추가**. 하루 구슬은 1개
- "구슬 넣기" 버튼과 안내 메시지(넣기 / 더 답하기)는 **없앰** → 사용자가 따로 할 일 없음
- 남은 질문은 자정 전까지 언제든 답할 수 있음
- 배경: 1~2개일 때 선택지를 띄우는 건 부담스럽다는 리뷰 의견 (FigJam 코멘트)

남은 작은 결정 (🟡)
- 두 번째 · 세 번째 답을 했을 때 반응: 없음 / 유령 한마디 정도

### A-3. ✅ 구슬 색 — 결정 (2026-11-18)
**결정: 우선 단색.** 점수에 따라 색을 나누지 않음

- 기존 안([화면-구슬병.md](legacy/화면-구슬병.md) 연속 그라데이션)과 흐름도 안(빨강 · 노랑 · 초록 3단계)은 **보류**
- 특별한 구슬은 모양(반짝임 등)으로만 구분
- 답변 점수는 계속 저장 → 나중에 점수별 색을 넣을 때 다시 논의 (그때 경계값, 색약 대응 함께 정함)
- 남은 작업: [화면-구슬병.md](legacy/화면-구슬병.md) 의 "구슬 색 = 그날 퇴사각", "항목 클릭 → 해당 구슬만 빛나기" 등 색 관련 내용 정리
- 남은 작은 결정 (⚪): 단색의 실제 색 (유령 · 병 디자인과 맞춰 정함)

### A-4. ✅ 유리병이 늘 떠 있는지 — 결정 (2026-11-18)
**결정: 바탕화면에 늘 떠 있지 않음. 유령을 우클릭했을 때만 유령 옆에 유리병 선반이 나타남**

- 우클릭 메뉴와 함께 선반이 나타나고, 메뉴를 닫으면 함께 사라짐
- 구슬 넣기 연출 때는 지금처럼 이번 달 병이 잠깐 나타났다 사라짐
- 따로 뜨는 "선반 창"은 없음 → "모든 연출은 유령 주변에서만" 원칙과 맞음
- 우클릭 메뉴의 "기록 보기" 항목은 뺌
- 남은 작업: [화면-구슬병.md](legacy/화면-구슬병.md) 의 "병이 바탕화면에 늘 떠 있음", 병 드래그 · 흔들기, 병 위치 정하기, 병 숨기기 내용 정리

남은 작은 결정 (🟡)
- **선반이 언제 닫히는지**: 병을 눌러 구슬을 펼치거나 구슬을 눌러 답변을 보는 중에는 메뉴가 닫혀도 유지해야 함 → "선반 바깥을 클릭하면 닫힘"으로 할지
- **유령을 숨긴 상태에서 기록 보기**: 트레이 메뉴의 "기록 보기"를 누르면 유령이 잠깐 나타나면서 선반을 보여줄지, 트레이 아이콘 근처에 선반을 띄울지
- 유령이 화면 가장자리에 있을 때 선반이 나오는 방향 (왼쪽 / 오른쪽 / 위)
- 펼친 구슬(한 달 31개)과 답변 상세를 유령 옆 좁은 공간에 어떻게 배치할지

### A-5. 🔴 친밀도 — 요인 확정 (2026-11-18), 점수 규칙 정리 필요
**결정: 친밀도가 오르는 요인 3가지**

| # | 요인 | 기준 |
| --- | --- | --- |
| 1 | 유령 쓰다듬기 | 쓰다듬은 횟수 |
| 2 | 질문 답변 여부 | **하루 단위**로 답했는지만 봄 (답변 개수는 일단 반영 안 함, 나중에 확장 가능) |
| 3 | 유령이 나타나 있던 시간 | 데스크톱에 유령이 떠 있던 시간 |

| 기존 ([ERD.md](legacy/ERD.md)) | 변경 |
| --- | --- |
| **레벨 · 경험치**(기록량) + **애정도**(쓰다듬기) 두 축 | **친밀도** 하나, 5단계 |

정할 것
- 요인별 점수 (예: 쓰다듬기 1번 +1, 질문에 답한 날 +10, 나타나 있던 1시간 +2)
- **하루 상한값**과 요인별 상한 (쓰다듬기 연타 · 켜두기만으로 채우는 것 막기)
- 질문 답변 여부: 단기와 장기를 **따로** 셀지 (이달의 질문에 답한 날은 더 줄지)
- 나타나 있던 시간: **숨김 상태 · 졸기 상태**도 포함할지, 컴퓨터를 안 쓰는 시간(자리 비움)은 뺄지
- 단계별 필요 점수 (5단계 곡선)
- 단계별로 열리는 대사 · 행동 목록
- 기존 레벨 · 경험치 · 애정도를 **친밀도 하나로 합칠지** → [ERD.md](legacy/ERD.md) `user_pets`, `exp_events` 수정
- 참고: 기존 `exp_events`(경험치 장부) 구조는 친밀도 장부로 그대로 쓸 수 있음 (요인별 `source_type`: 쓰다듬기 / 답변한 날 / 나타난 시간)

### A-6. 🟡 장기 질문 주기
**지표는 확정**: 복지 · 조직문화 · 고용 · 사업 안정성 3개, 측정 주기 **분기별** ([기획정리.md](기획정리.md) 4. 이달의 질문)

| 기존 ([ERD.md](legacy/ERD.md)) | 확정된 지표 | 흐름도 |
| --- | --- | --- |
| 장기 지표 **8개**, 월 · 분기 질문 | 장기 지표 **3개**, **분기별** | **한 달에 한 번**, 3개 중 1개 골라 답함 |

- 정할 것
  - **분기별 측정과 월 1회 이벤트를 어떻게 맞출지**
    - 안 1. 매달 3개 중 1개 고르기, 분기 안에서 이미 답한 지표는 빠짐 → 3달이면 3개 모두 답함
    - 안 2. 매달 아무거나 고르기 → 지표별로 가장 최근 답변을 이월 (기존 ERD 방식)
    - 안 3. 이벤트도 분기에 한 번만
  - "정해진 날"이 언제인지 (매월 1일 / 마지막 금요일 / 사용자별 다름)
  - 그날 답하지 않으면? (다음 날까지 유지 / 그 달은 없음)
  - 그날 오늘의 질문도 같이 나오는지
- 남은 작업: [ERD.md](legacy/ERD.md) 의 "장기 지표 8개" → **3개**로 수정

### A-9. 🔴 답변 → 점수(0~100) 변환 규칙
설문 방식이 정해졌으니, 각 답변을 [ERD.md](legacy/ERD.md) 규칙대로 **0~100점 (높을수록 퇴사각↑)** 으로 바꾸는 기준이 필요함

| 지표 | 답변 형태 | 정할 것 |
| --- | --- | --- |
| 퇴사 충동 | 도장 횟수 | **최대 횟수** (예: 10번 = 100점), 0번 허용 여부 |
| 업무 스트레스 | 풍선 크기 | 크기 단계 (연속값 / n단계), 최대 크기 |
| 업무량 | 서류 높이 | **최대 높이**와 점수 매핑. 랜드마크 목록 (예: 책상 → 사람 키 → 롯데타워) |
| 감정 소모 | HP 0~100 | HP가 **줄어들수록** 지친 것 → `100 - HP` 로 뒤집는지 확인 |
| 성취감 | 3개 중 1개 | 3단계 점수 (예: 때려치워 100 / 이걸해냄 50 / 내가짱이야 0). 긍정 지표라 뒤집기 |
| 복지 | 3개 중 1개 | 쓸모 있음 / 그럭저럭 / 귀중품 점수. 긍정 지표 |
| 조직문화 | 3개 중 1개 | 편한 자세 / 그냥 앉아 있는 자세 / 군기 들어있는 자세 점수 |
| 고용 · 사업 안정성 | 3개 중 1개 | 맑음 / 구름 / 폭풍 점수 |

- 확인: 업무량 질문은 "감당할 수 있는 수준이었나요?" (긍정 문장)인데 답변은 "느낀 업무량만큼 쌓기" (많을수록 나쁨) → 질문 문구와 답변 방향을 맞출지
- 확인: 3지선다(성취감 · 장기 지표)는 점수 간격이 커서 날마다 점수가 크게 흔들림 → 괜찮은지
- 참고: 구슬 색은 우선 단색(A-3)이지만, 나중에 점수별 색을 넣으려면 이 규칙이 기준이 됨

### A-10. 🔴 퇴사각 지수 계산 방식
구슬을 누르면 보이는 숫자를 어떻게 계산할지

- 기존 ([ERD.md](legacy/ERD.md)): 단기 점수(최근 7일) × 0.6 + 장기 점수(월 · 분기) × 0.4 = 종합 점수
- 정할 것
  - **그날 답한 단기 질문의 평균**만 쓸지 (단순, 날마다 독립적) vs 기존처럼 최근 7일 · 장기 점수를 섞을지
  - 특별한 구슬(이달의 질문)의 숫자: 그 답변 1개의 점수만 보여줄지
  - 답이 1개뿐인 날도 그대로 보여줄지 (질문마다 점수 기준이 달라 날짜끼리 비교가 어려움)
- 답변 → 점수 변환(A-9)이 먼저 정해져야 함
